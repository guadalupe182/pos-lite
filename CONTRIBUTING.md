# Contribuir a POS-lite

¡Gracias por tu interés en contribuir! Este proyecto sigue principios open source y agradece cualquier ayuda.

## 📌 Código de Conducta

Este proyecto sigue el [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/). Al participar, aceptas respetarlo.

## 🧠 Filosofía del Proyecto

- **Compartir código**: Todo el código académico/open source es público y libre (MIT).
- **Mejorar juntos**: Pull requests, issues y discusiones son bienvenidas.
- **Respetar la licencia dual**: Si usas el código con fines comerciales, adquiere una licencia comercial.

## 🛠️ ¿Cómo contribuir?

1. **Reportar errores**: Abre un issue describiendo el problema (incluye logs si aplica).
2. **Sugerir mejoras**: Usa el template de "Feature request".
3. **Enviar código**:
   - Haz un fork del repositorio.
   - Crea una rama (`git checkout -b feature/mi-mejora`).
   - Sigue el estilo de código existente (Java 17, Spring Boot conventions).
   - Escribe pruebas si aplica.
   - Haz commit y push.
   - Abre un Pull Request hacia `main`.
4. **Documentar**: Actualiza el README o la wiki si tus cambios afectan la instalación o uso.

## ✅ Requisitos del código

- Java 17, Maven, Spring Boot 3.x.
- Formato: Usa la indentación del proyecto (4 espacios, no tabs).
- Las pruebas deben pasar (`mvn test`).
- Incluye comentarios Javadoc en métodos públicos.

## 🔒 Nota sobre la Licencia Comercial

Los colaboradores aceptan que sus contribuciones al repositorio público (MIT) también quedarán bajo la licencia MIT. Si tu contribución tiene valor comercial, contacta antes a los mantenedores para acordar términos separados.
